Why ToolXStack

One app instead of a drawer of ad-heavy single-purpose apps and web converters that see everything you paste.

  • Nothing can leave

    The release build strips Android’s INTERNET permission, so the system itself refuses any network request. A test in the build checks it stays that way.

  • Works anywhere

    On a flight, underground or in a locked-down data centre. Every tool runs on your phone with no connection.

  • Everything in one place

    57 developer tools, 32 unit converters, 22 finance calculators and more, behind one search that understands emi, b64 and dob.

  • Learn as you go

    Each tool has a short article with the formula and a worked example, plus 37 offline guides on HTTP, regex, cron, Git, hashing and more.

  • Fits every screen

    Phones, foldables, tablets and Chromebooks. Wide screens get two panes, and a keyboard works: Enter runs a tool, Escape closes a sheet.

  • Free, with no catch

    No ads, no in-app purchases, no pro tier and no account. Apache-2.0 on GitHub.

Your data stays on your device

ToolXStack collects nothing, because it can’t send anything. The privacy policy is short for a reason.

Read the privacy policy
  • Blocked by Android, not by promiseNo INTERNET or network-state permission. The only permission is vibrate, for haptics.
  • No analytics or crash reportsNo tracking SDKs and no behaviour logging.
  • Your inputs are never savedFavourites and recents keep only tool IDs and times, never what you typed.
  • Clipboard only when you tapToolXStack reads or writes the clipboard only when you press a button.

Install in a minute

ToolXStack is shared on GitHub rather than an app store, so there is no store account and no store tracking.

  1. Download the APK

    Open the latest release on your phone and download the .apk file.

  2. Allow the install

    Tap the file. If Android asks, allow your browser or file manager to install apps, just this once.

  3. Check it, if you like

    Each release has a SHA-256 checksum. Run sha256sum -c ToolXStack-vX.Y.Z.apk.sha256 to confirm your download is the published file.

Questions

Does it really work without internet?

Yes. Every tool runs on your phone, and the app has no permission to use the network at all.

Is anything I paste stored?

No. Favourites and recents store only which tool you used and when, never your inputs or results.

Why is it on GitHub and not the Play Store?

Releases on GitHub come with a SHA-256 checksum for every build, so you can check exactly what you install, and there is no store in between collecting data.

Which Android versions are supported?

Android 13 (API 33) and newer, on phones, foldables, tablets and Chromebooks that run Android apps.

Is it really free?

Yes. ToolXStack is free and open source under Apache-2.0, with no ads, subscriptions or in-app purchases.

How do I report a bug or ask for a tool?

Open an issue on GitHub. Pull requests are welcome too.
